Əməliyyat sistemləri — test

25 sual · Əməliyyat sistemləri
▶ Testi interaktiv həll et

1. Əməliyyat sisteminin nüvəsi (kernel) nədir?

  1. Aparat resurslarını birbaşa idarə edən əsas hissə
  2. Qrafik interfeys
  3. Brauzer
  4. Mətn redaktoru
Cavabı göstər

A) Aparat resurslarını birbaşa idarə edən əsas hissə

2. Proses nədir?

  1. Diskdəki fayl
  2. Qovluq
  3. Prosessorun nüvəsi
  4. İcra olunmaqda olan proqram
Cavabı göstər

D) İcra olunmaqda olan proqram

3. Axın (thread) nədir?

  1. Yaddaş səhifəsi
  2. Ayrıca kompüter
  3. Şəbəkə kabeli
  4. Proses daxilində icranın ayrıca ardıcıllığı
Cavabı göstər

D) Proses daxilində icranın ayrıca ardıcıllığı

4. Çoxtapşırıqlılıq (multitasking) nədir?

  1. Bir neçə istifadəçinin eyni parolu
  2. Diskin bölmələrə ayrılması
  3. Bir neçə monitorun qoşulması
  4. Bir neçə prosesin eyni vaxtda (növbə ilə) icrası
Cavabı göstər

D) Bir neçə prosesin eyni vaxtda (növbə ilə) icrası

5. Kilidlənmə (deadlock) nədir?

  1. Kompüterin parolla bağlanması
  2. Proqramın sürətli işləməsi
  3. Faylın silinməsi
  4. Proseslərin bir-birinin tutduğu resursu sonsuz gözləməsi
Cavabı göstər

D) Proseslərin bir-birinin tutduğu resursu sonsuz gözləməsi

6. Deadlock üçün zəruri şərtlərdən biri hansıdır?

  1. Prosessorun yüksək tezliyi
  2. Dairəvi gözləmə
  3. Böyük disk
  4. Sürətli internet
Cavabı göstər

B) Dairəvi gözləmə

7. FCFS planlaşdırma alqoritmi necə işləyir?

  1. Ən qısa prosesi birinci icra edir
  2. Ən uzun prosesi birinci icra edir
  3. Prosesləri təsadüfi seçir
  4. Prosesləri gəlmə ardıcıllığı ilə icra edir
Cavabı göstər

D) Prosesləri gəlmə ardıcıllığı ilə icra edir

8. Round Robin alqoritminin əsas xüsusiyyəti nədir?

  1. Proseslər heç vaxt dayandırılmır
  2. Yalnız bir proses icra olunur
  3. Prioritet həmişə ən yüksəkdir
  4. Hər prosesə növbə ilə sabit vaxt kvantı verilir
Cavabı göstər

D) Hər prosesə növbə ilə sabit vaxt kvantı verilir

9. Virtual yaddaş nədir?

  1. Fləş-kart
  2. Prosessorun keşi
  3. Diskin bir hissəsinin əməliyyat yaddaşının davamı kimi istifadəsi
  4. Bulud yaddaşı
Cavabı göstər

C) Diskin bir hissəsinin əməliyyat yaddaşının davamı kimi istifadəsi

10. Səhifə (page) uğursuzluğu (page fault) nə vaxt baş verir?

  1. İnternet kəsildikdə
  2. Proqram bağlandıqda
  3. Lazım olan səhifə əməliyyat yaddaşında olmadıqda
  4. Disk dolduqda
Cavabı göstər

C) Lazım olan səhifə əməliyyat yaddaşında olmadıqda

11. LRU səhifə əvəzetmə alqoritmi hansı səhifəni çıxarır?

  1. Təsadüfi səhifəni
  2. Ən uzun müddət istifadə olunmamış səhifəni
  3. Ən yeni yüklənmiş səhifəni
  4. Ən çox istifadə olunan səhifəni
Cavabı göstər

B) Ən uzun müddət istifadə olunmamış səhifəni

12. Keş (cache) yaddaşın məqsədi nədir?

  1. Virusları silmək
  2. Faylları arxivləşdirmək
  3. Ekranı işıqlandırmaq
  4. Tez-tez istifadə olunan məlumatlara müraciəti sürətləndirmək
Cavabı göstər

D) Tez-tez istifadə olunan məlumatlara müraciəti sürətləndirmək

13. Semafor nə üçün istifadə olunur?

  1. Şəbəkə ünvanının təyini üçün
  2. Proseslərin sinxronlaşdırılması və ortaq resursa girişin idarəsi üçün
  3. Ekranın rənginin dəyişdirilməsi üçün
  4. Faylların sıxılması üçün
Cavabı göstər

B) Proseslərin sinxronlaşdırılması və ortaq resursa girişin idarəsi üçün

14. Kritik seksiya nədir?

  1. Ortaq resursla işləyən və eyni anda yalnız bir prosesin icra etməli olduğu kod hissəsi
  2. Diskin zədələnmiş sahəsi
  3. Prosessorun ən isti nöqtəsi
  4. Əməliyyat sisteminin yüklənməsi
Cavabı göstər

A) Ortaq resursla işləyən və eyni anda yalnız bir prosesin icra etməli olduğu kod hissəsi

15. Drayver nədir?

  1. Əməliyyat sisteminin konkret qurğu ilə işləməsini təmin edən proqram
  2. Antivirus
  3. Fayl meneceri
  4. Kompüterin istifadəçisi
Cavabı göstər

A) Əməliyyat sisteminin konkret qurğu ilə işləməsini təmin edən proqram

16. Linux-da cari qovluğun məzmununu göstərən əmr hansıdır?

  1. ls
  2. mkdir
  3. cd
  4. rm
Cavabı göstər

A) ls

17. Linux-da yeni qovluq yaradan əmr hansıdır?

  1. touch
  2. rmdir
  3. mkdir
  4. pwd
Cavabı göstər

C) mkdir

18. Linux-da cari qovluğun tam yolunu göstərən əmr hansıdır?

  1. ls
  2. whoami
  3. cat
  4. pwd
Cavabı göstər

D) pwd

19. Linux-da administrator (superuser) hüquqları ilə əmri icra etmək üçün nə istifadə olunur?

  1. admin
  2. runas
  3. sudo
  4. chmod
Cavabı göstər

C) sudo

20. Linux-da fayl icazələrini dəyişən əmr hansıdır?

  1. chown
  2. cp
  3. mv
  4. chmod
Cavabı göstər

D) chmod

21. Windows-da tipik fayl sistemi hansıdır?

  1. APFS
  2. ext4
  3. HFS
  4. NTFS
Cavabı göstər

D) NTFS

22. Linux-da geniş yayılmış fayl sistemi hansıdır?

  1. NTFS
  2. APFS
  3. ext4
  4. FAT12
Cavabı göstər

C) ext4

23. Kəsilmə (interrupt) nədir?

  1. Proqramın quraşdırılması
  2. Faylın silinməsi
  3. Elektrik enerjisinin kəsilməsi
  4. Prosessora diqqət tələb edən hadisə barədə siqnal
Cavabı göstər

D) Prosessora diqqət tələb edən hadisə barədə siqnal

24. Əməliyyat sisteminin yüklənməsi (boot) prosesində ilk işə düşən nədir?

  1. BIOS/UEFI proqramı
  2. Mətn redaktoru
  3. Antivirus
  4. Brauzer
Cavabı göstər

A) BIOS/UEFI proqramı

25. Real vaxt əməliyyat sistemi (RTOS) üçün nə vacibdir?

  1. Böyük disk həcmi
  2. Çoxlu oyun
  3. Hadisələrə dəqiq müəyyən olunmuş vaxt ərzində cavab vermək
  4. Gözəl qrafik interfeys

C) Hadisələrə dəqiq müəyyən olunmuş vaxt ərzində cavab vermək
