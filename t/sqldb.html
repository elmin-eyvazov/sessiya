1. Cədvəldən məlumat seçmək üçün hansı SQL əmri istifadə olunur?

  1. EXTRACT
  2. OPEN
  3. SELECT
  4. GET
  5. SHOW
Cavabı göstər

C) SELECT

2. Sətirləri şərtə görə süzgəcdən keçirmək üçün hansı ifadə istifadə olunur?

  1. FROM
  2. WHERE
  3. JOIN
  4. ORDER BY
  5. GROUP BY
Cavabı göstər

B) WHERE

3. Nəticəni azalma sırası ilə düzmək üçün nə yazılır?

  1. SORT DOWN
  2. ORDER ... REVERSE
  3. ORDER BY ... DESC
  4. GROUP BY ... DESC
  5. ORDER BY ... ASC
Cavabı göstər

C) ORDER BY ... DESC

4. Cədvələ yeni sətir əlavə edən əmr hansıdır?

  1. ADD ROW
  2. INSERT INTO
  3. APPEND
  4. UPDATE
  5. CREATE
Cavabı göstər

B) INSERT INTO

5. Mövcud sətirlərin qiymətlərini dəyişən əmr hansıdır?

  1. UPDATE
  2. SET
  3. MODIFY
  4. CHANGE
  5. ALTER
Cavabı göstər

A) UPDATE

6. Cədvəldən sətirləri silən əmr hansıdır?

  1. DROP
  2. REMOVE
  3. DELETE
  4. CLEAR
  5. ERASE
Cavabı göstər

C) DELETE

7. Cədvəli bütövlükdə (strukturu ilə birlikdə) silən əmr hansıdır?

  1. TRUNCATE ROW
  2. DELETE TABLE
  3. DROP TABLE
  4. REMOVE TABLE
  5. CLEAR TABLE
Cavabı göstər

C) DROP TABLE

8. Birinci açar (PRIMARY KEY) üçün hansı fikir doğrudur?

  1. Yalnız mətn ola bilər
  2. Hər cədvəldə bir neçə dənə olur
  3. NULL ola bilər
  4. Unikal və NULL olmayan olmalıdır
  5. Təkrarlana bilər
Cavabı göstər

D) Unikal və NULL olmayan olmalıdır

9. Xarici açar (FOREIGN KEY) nə üçündür?

  1. Sorğunu sürətləndirmək
  2. Cədvəli şifrələmək
  3. Başqa cədvəlin açarına istinad edərək cədvəlləri əlaqələndirmək
  4. Sütunu gizlətmək
  5. Təkrarları silmək
Cavabı göstər

C) Başqa cədvəlin açarına istinad edərək cədvəlləri əlaqələndirmək

10. Sətirlərin sayını hansı funksiya qaytarır?

  1. LEN(*)
  2. COUNT(*)
  3. SUM(*)
  4. NUM(*)
  5. TOTAL(*)
Cavabı göstər

B) COUNT(*)

11. Orta qiyməti hansı funksiya hesablayır?

  1. MEAN()
  2. MEDIAN()
  3. SUM()/2
  4. MID()
  5. AVG()
Cavabı göstər

E) AVG()

12. Sətirləri qruplaşdırmaq üçün hansı ifadə istifadə olunur?

  1. GROUP BY
  2. ORDER BY
  3. DISTINCT
  4. UNION
  5. HAVING
Cavabı göstər

A) GROUP BY

13. Qruplara şərt qoymaq üçün hansı ifadə istifadə olunur?

  1. ON
  2. LIMIT
  3. WHERE
  4. HAVING
  5. IF
Cavabı göstər

D) HAVING

14. INNER JOIN hansı sətirləri qaytarır?

  1. Hər iki cədvəldə uyğunluğu olan sətirləri
  2. Sol cədvəlin bütün sətirlərini
  3. Sağ cədvəlin bütün sətirlərini
  4. Bütün mümkün kombinasiyaları
  5. Uyğunluğu olmayan sətirləri
Cavabı göstər

A) Hər iki cədvəldə uyğunluğu olan sətirləri

15. LEFT JOIN hansı sətirləri qaytarır?

  1. Sağ cədvəlin bütün sətirlərini
  2. Yalnız uyğun sətirləri
  3. Sol cədvəlin bütün sətirlərini və sağdan uyğun olanları
  4. Yalnız NULL sətirləri
  5. Heç birini
Cavabı göstər

C) Sol cədvəlin bütün sətirlərini və sağdan uyğun olanları

16. Təkrarlanan qiymətləri nəticədən çıxarmaq üçün nə yazılır?

  1. DIFFERENT
  2. DISTINCT
  3. ONLY
  4. SINGLE
  5. UNIQUE
Cavabı göstər

B) DISTINCT

17. name LIKE 'A%' şərti hansı sətirləri seçir?

  1. A ilə bitənləri
  2. İki hərfli adları
  3. İçində A olmayanları
  4. Tam olaraq 'A' olanları
  5. A ilə başlayanları
Cavabı göstər

E) A ilə başlayanları

18. Sütunun boş (NULL) olmasını necə yoxlamaq olar?

  1. = NULL
  2. NULL()
  3. IS NULL
  4. == NULL
  5. EQUALS NULL
Cavabı göstər

C) IS NULL

19. BETWEEN 10 AND 20 şərti haqqında hansı fikir doğrudur?

  1. 10 və 20 daxil deyil
  2. Yalnız tam ədədlərlə işləyir
  3. 10 və 20 daxildir
  4. Yalnız 20 daxildir
  5. Yalnız 10 daxildir
Cavabı göstər

C) 10 və 20 daxildir

20. Birinci normal formanın (1NF) əsas tələbi nədir?

  1. Cədvəlin 3 sütundan az olması
  2. İndekslərin olması

  5. Tranzitiv asılılığın olmaması

C) Hər sütunda atomar (bölünməz) qiymətlər
