Marketinqin əsasları — test

25 sual · Marketinq
▶ Testi interaktiv həll et

1. Marketinq nədir?

  1. Yalnız məhsulun satışı
  2. Yalnız reklam
  3. Müştəri tələbatını öyrənib onu mənfəətlə ödəməyə yönəlmiş fəaliyyət
  4. Mühasibat uçotu
Cavabı göstər

C) Müştəri tələbatını öyrənib onu mənfəətlə ödəməyə yönəlmiş fəaliyyət

2. Marketinq kompleksinin «4P» modeli hansı elementlərdən ibarətdir?

  1. Plan, proses, personal, mənfəət
  2. Məhsul, qiymət, yer (bölgü), təşviq
  3. İstehsal, satış, reklam, xidmət
  4. Qiymət, gəlir, xərc, mənfəət
Cavabı göstər

B) Məhsul, qiymət, yer (bölgü), təşviq

3. Bazar seqmentləşdirilməsi nədir?

  1. Reklam kampaniyası
  2. Bazarın oxşar tələbatı olan istehlakçı qruplarına bölünməsi
  3. Məhsulun qablaşdırılması
  4. Məhsulun qiymətinin endirilməsi
Cavabı göstər

B) Bazarın oxşar tələbatı olan istehlakçı qruplarına bölünməsi

4. Hədəf bazar nədir?

  1. Şirkətin xidmət etmək üçün seçdiyi istehlakçı seqmenti
  2. Bütün ölkə əhalisi
  3. Dövlət qurumları
  4. Rəqiblərin müştəriləri
Cavabı göstər

A) Şirkətin xidmət etmək üçün seçdiyi istehlakçı seqmenti

5. Mövqeləndirmə (positioning) nədir?

  1. Qiyməti artırmaq
  2. Məhsulu anbarda yerləşdirmək
  3. Məhsula istehlakçının şüurunda rəqiblərdən fərqli yer qazandırmaq
  4. Mağazada rəfdə yer seçmək
Cavabı göstər

C) Məhsula istehlakçının şüurunda rəqiblərdən fərqli yer qazandırmaq

6. Məhsulun həyat dövrünün mərhələləri hansılardır?

  1. Bazara çıxış, artım, yetkinlik, tənəzzül
  2. Alış, istifadə, təmir, utilizasiya
  3. Dizayn, test, buraxılış, reklam
  4. Plan, istehsal, satış, mənfəət
Cavabı göstər

A) Bazara çıxış, artım, yetkinlik, tənəzzül

7. Məhsulun həyat dövründə satışın ən yüksək olduğu mərhələ hansıdır?

  1. Hazırlıq
  2. Tənəzzül
  3. Bazara çıxış
  4. Yetkinlik
Cavabı göstər

D) Yetkinlik

8. Bazara yeni məhsulu aşağı qiymətlə çıxarıb tez bazar payı qazanmaq strategiyası necə adlanır?

  1. «Qaymağın yığılması» strategiyası
  2. Psixoloji qiymət
  3. Prestij qiymət strategiyası
  4. Bazara nüfuz etmə strategiyası
Cavabı göstər

D) Bazara nüfuz etmə strategiyası

9. Yeni məhsulu əvvəlcə yüksək qiymətlə satmaq strategiyası necə adlanır?

  1. Bazara nüfuz etmə strategiyası
  2. Damping
  3. Endirim strategiyası
  4. «Qaymağın yığılması» (skimminq) strategiyası
Cavabı göstər

D) «Qaymağın yığılması» (skimminq) strategiyası

10. Qiymətin 10 manat yerinə 9,99 manat qoyulması hansı qiymət növüdür?

  1. Prestij qiymət
  2. Psixoloji qiymət
  3. Tənzimlənən qiymət
  4. Damping qiyməti
Cavabı göstər

B) Psixoloji qiymət

11. Brend nədir?

  1. Məhsulu rəqiblərdən fərqləndirən ad, işarə, dizayn və təəssüratlar məcmusu
  2. Satış meneceri
  3. Məhsulun maya dəyəri
  4. Anbardakı məhsul ehtiyatı
Cavabı göstər

A) Məhsulu rəqiblərdən fərqləndirən ad, işarə, dizayn və təəssüratlar məcmusu

12. Birinci dərəcəli (ilkin) məlumat necə əldə olunur?

  1. Rəqiblərin hesabatlarından
  2. İnternetdəki məqalələrdən
  3. Hazır statistik məcmuələrdən
  4. Tədqiqatçının özünün apardığı sorğu, müşahidə və ya eksperiment yolu ilə
Cavabı göstər

D) Tədqiqatçının özünün apardığı sorğu, müşahidə və ya eksperiment yolu ilə

13. Fokus-qrup nədir?

  1. Satış komandası
  2. Reklam çəkiliş qrupu
  3. Kiçik qrup istehlakçı ilə moderatorun apardığı müzakirə şəklində tədqiqat
  4. Anbar işçiləri
Cavabı göstər

C) Kiçik qrup istehlakçı ilə moderatorun apardığı müzakirə şəklində tədqiqat

14. Satışın həvəsləndirilməsinə nə aiddir?

  1. İşçilərin işə qəbulu
  2. Vergilərin ödənilməsi
  3. Endirimlər, kuponlar, «1 al, 1 qazan» aksiyaları
  4. Məhsulun istehsalı
Cavabı göstər

C) Endirimlər, kuponlar, «1 al, 1 qazan» aksiyaları

15. İctimaiyyətlə əlaqələr (PR) nəyə yönəlib?

  1. Maaşların hesablanmasına
  2. Yalnız birbaşa satışa
  3. Xammal alışına
  4. Şirkətin müsbət imicinin və ictimai etimadın formalaşmasına
Cavabı göstər

D) Şirkətin müsbət imicinin və ictimai etimadın formalaşmasına

16. B2B marketinq nədir?

  1. Dövlətin vətəndaşlara xidməti
  2. Şirkətin fərdi istehlakçılara satışı
  3. İstehlakçılar arasında satış
  4. Şirkətlərin digər şirkətlərə məhsul və xidmət satışı
Cavabı göstər

D) Şirkətlərin digər şirkətlərə məhsul və xidmət satışı

17. B2C marketinq nədir?

  1. Şirkətlər arası satış
  2. Dövlət satınalmaları
  3. Birja ticarəti
  4. Şirkətin fərdi istehlakçılara satışı
Cavabı göstər

D) Şirkətin fərdi istehlakçılara satışı

18. SWOT təhlilində «O» hərfi nəyi bildirir?

  1. Məqsədləri (Objectives)
  2. Sifarişləri (Orders)
  3. Əməliyyatları (Operations)
  4. İmkanları (Opportunities)
Cavabı göstər

D) İmkanları (Opportunities)

19. Birbaşa marketinq nədir?

  1. Televiziya reklamı
  2. Vasitəçisiz, fərdi müraciətlə (e-poçt, zəng, SMS) müştəriyə satış
  3. Sərgidə iştirak
  4. Topdan satış
Cavabı göstər

B) Vasitəçisiz, fərdi müraciətlə (e-poçt, zəng, SMS) müştəriyə satış

20. Bölgü kanalının uzunluğu nə ilə müəyyən olunur?

  1. Yolun kilometrlə uzunluğu ilə
  2. Məhsulun çəkisi ilə
  3. İstehsalçı ilə istehlakçı arasındakı vasitəçilərin sayı ilə
  4. Reklamın müddəti ilə
Cavabı göstər

C) İstehsalçı ilə istehlakçı arasındakı vasitəçilərin sayı ilə

21. Loyallıq proqramlarının məqsədi nədir?

  1. Müştərini saxlamaq və təkrar alışları artırmaq
  2. Rəqibi bazardan çıxarmaq
  3. Xərcləri artırmaq
  4. Yeni işçi tapmaq
Cavabı göstər

A) Müştərini saxlamaq və təkrar alışları artırmaq

22. Rəqəmsal marketinqdə SEO nəyi bildirir?

  1. Satış hesabatını
  2. Elektron poçt göndərişini
  3. Sosial şəbəkədə ödənişli reklamı
  4. Saytın axtarış sistemlərində optimallaşdırılmasını
Cavabı göstər

D) Saytın axtarış sistemlərində optimallaşdırılmasını

23. Konversiya (çevrilmə) əmsalı nəyi göstərir?

  1. Reklamın qiymətini
  2. Məhsulun maya dəyərini
  3. Hədəf hərəkəti (alış, qeydiyyat) edən ziyarətçilərin faizini
  4. Saytın yüklənmə sürətini
Cavabı göstər

C) Hədəf hərəkəti (alış, qeydiyyat) edən ziyarətçilərin faizini

24. Marketinqin mikromühitinə nə aiddir?

  1. Müştərilər, rəqiblər, təchizatçılar, vasitəçilər
  2. İqlim şəraiti
  3. Dünya iqtisadiyyatı
  4. Demoqrafik və siyasi amillər
Cavabı göstər

A) Müştərilər, rəqiblər, təchizatçılar, vasitəçilər

25. Marketinqin makromühitini təhlil üçün hansı model istifadə olunur?

  1. BCG matrisi
  2. 4P
  3. PEST təhlili
  4. AIDA
Cavabı göstər

C) PEST təhlili
