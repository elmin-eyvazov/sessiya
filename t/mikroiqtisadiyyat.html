Mikroiqtisadiyyat — test

25 sual · Mikroiqtisadiyyat
▶ Testi interaktiv həll et

1. Mikroiqtisadiyyat nəyi öyrənir?

  1. İnflyasiya və işsizliyin ümumi səviyyəsini
  2. Ölkənin ümumi daxili məhsulunu
  3. Dövlətin pul-kredit siyasətini
  4. Ayrı-ayrı istehlakçıların, firmaların və bazarların davranışını
Cavabı göstər

D) Ayrı-ayrı istehlakçıların, firmaların və bazarların davranışını

2. Tələb qanununa görə, digər şərtlər sabit qaldıqda qiymət artdıqca:

  1. Tələbin miqdarı artır
  2. Tələbin miqdarı azalır
  3. Təklif azalır
  4. Tələbin miqdarı dəyişmir
Cavabı göstər

B) Tələbin miqdarı azalır

3. Təklif qanununa görə qiymət artdıqca:

  1. Təklifin miqdarı azalır
  2. Təklif dəyişmir
  3. Təklifin miqdarı artır
  4. Tələb artır
Cavabı göstər

C) Təklifin miqdarı artır

4. Bazar tarazlığı nə vaxt yaranır?

  1. Təklif tələbdən çox olduqda
  2. Tələbin miqdarı təklifin miqdarına bərabər olduqda
  3. Dövlət qiyməti təyin etdikdə
  4. Qiymət maksimum olduqda
Cavabı göstər

B) Tələbin miqdarı təklifin miqdarına bərabər olduqda

5. Qiymət tarazlıq səviyyəsindən aşağı təyin edilərsə, bazarda nə yaranır?

  1. Tarazlıq
  2. Kəsir (defisit)
  3. Artıqlıq (izafə)
  4. İnflyasiya
Cavabı göstər

B) Kəsir (defisit)

6. Qiymət tarazlıq səviyyəsindən yuxarı təyin edilərsə, bazarda nə yaranır?

  1. Tarazlıq
  2. Deflyasiya
  3. Artıqlıq (izafə)
  4. Kəsir (defisit)
Cavabı göstər

C) Artıqlıq (izafə)

7. İstehlakçıların gəliri artdıqda normal əmtəəyə tələb necə dəyişir?

  1. Artır
  2. Azalır
  3. Dəyişmir
  4. Sıfıra enir
Cavabı göstər

A) Artır

8. Gəlir artdıqca tələbi azalan əmtəə necə adlanır?

  1. Normal əmtəə
  2. Əvəzedici əmtəə
  3. Aşağı keyfiyyətli (inferior) əmtəə
  4. Dəbdəbə əmtəəsi
Cavabı göstər

C) Aşağı keyfiyyətli (inferior) əmtəə

9. Çay və qəhvə bir-birinə nisbətən hansı əmtəələrdir?

  1. Əvəzedici əmtəələr
  2. Aşağı keyfiyyətli əmtəələr
  3. Əlaqəsiz əmtəələr
  4. Tamamlayıcı əmtəələr
Cavabı göstər

A) Əvəzedici əmtəələr

10. Avtomobil və benzin bir-birinə nisbətən hansı əmtəələrdir?

  1. Giffen əmtəələri
  2. Əlaqəsiz əmtəələr
  3. Əvəzedici əmtəələr
  4. Tamamlayıcı əmtəələr
Cavabı göstər

D) Tamamlayıcı əmtəələr

11. Tələbin qiymətə görə elastikliyi 1-dən böyükdürsə, tələb necə adlanır?

  1. Elastik
  2. Tam qeyri-elastik
  3. Vahid elastik
  4. Qeyri-elastik
Cavabı göstər

A) Elastik

12. Tələb qeyri-elastik olduqda qiymət artarsa, satıcının ümumi gəliri:

  1. Sıfıra enir
  2. Dəyişmir
  3. Azalır
  4. Artır
Cavabı göstər

D) Artır

13. Son hədd faydalılığın azalması qanunu nəyi ifadə edir?

  1. Qiymət artdıqca fayda artır
  2. Hər vahid eyni fayda verir
  3. Əmtəənin hər əlavə vahidi əvvəlkindən daha az fayda verir
  4. Ümumi fayda həmişə azalır
Cavabı göstər

C) Əmtəənin hər əlavə vahidi əvvəlkindən daha az fayda verir

14. Alternativ (imkan) xərc nədir?

  1. Seçim zamanı imtina edilən ən yaxşı alternativin dəyəri
  2. Vergi xərcləri
  3. Məhsulun pul ilə ifadə olunan qiyməti
  4. Sabit xərclərin cəmi
Cavabı göstər

A) Seçim zamanı imtina edilən ən yaxşı alternativin dəyəri

15. Sabit xərclər hansılardır?

  1. Elektrik enerjisi sərfi
  2. Xammal xərcləri
  3. İşəmuzd əmək haqqı
  4. İstehsalın həcmindən asılı olmayan xərclər (məs. icarə haqqı)
Cavabı göstər

D) İstehsalın həcmindən asılı olmayan xərclər (məs. icarə haqqı)

16. Ümumi xərclər (TC) necə hesablanır?

  1. Orta xərc × qiymət
  2. Gəlir − mənfəət
  3. Sabit xərclər + dəyişən xərclər
  4. Qiymət × miqdar
Cavabı göstər

C) Sabit xərclər + dəyişən xərclər

17. Son hədd xərci (MC) nədir?

  1. Orta xərc
  2. Sabit xərclərin cəmi
  3. Ümumi gəlirin artımı
  4. Məhsulun bir əlavə vahidinin istehsalı nəticəsində xərclərin artımı
Cavabı göstər

D) Məhsulun bir əlavə vahidinin istehsalı nəticəsində xərclərin artımı

18. Firma mənfəəti maksimumlaşdırmaq üçün hansı şərtə əməl edir?

  1. MC = AVC
  2. TR = TC
  3. MR = MC
  4. P = AFC
Cavabı göstər

C) MR = MC

19. Mükəmməl rəqabət bazarının xüsusiyyəti hansıdır?

  1. Bir satıcı
  2. Fərqləndirilmiş məhsul və reklam
  3. Çoxlu satıcı və alıcı, eyni məhsul, firmalar qiymətə təsir edə bilmir
  4. Bir neçə iri firma
Cavabı göstər

C) Çoxlu satıcı və alıcı, eyni məhsul, firmalar qiymətə təsir edə bilmir

20. Bazarda yalnız bir satıcının olması necə adlanır?

  1. Oliqopoliya
  2. İnhisar (monopoliya)
  3. Mükəmməl rəqabət
  4. Monopsoniya
Cavabı göstər

B) İnhisar (monopoliya)

21. Bazarda bir neçə iri firmanın hökmranlığı necə adlanır?

  1. İnhisarçı rəqabət
  2. Mükəmməl rəqabət
  3. Monopoliya
  4. Oliqopoliya
Cavabı göstər

D) Oliqopoliya

22. Bazarda yalnız bir alıcının olması necə adlanır?

  1. Oliqopoliya
  2. Monopoliya
  3. Monopsoniya
  4. Duopoliya
Cavabı göstər

C) Monopsoniya

23. Qısa müddətli dövrdə firma nə vaxt istehsalı dayandırmalıdır?

  1. Qiymət orta ümumi xərcdən aşağı olduqda
  2. Mənfəət sıfır olduqda
  3. Sabit xərclər artdıqda
  4. Qiymət orta dəyişən xərcdən (AVC) aşağı olduqda
Cavabı göstər

D) Qiymət orta dəyişən xərcdən (AVC) aşağı olduqda

24. İstehsal amillərinə hansılar aiddir?

  1. Vergi, rüsum, aksiz
  2. Tələb, təklif, qiymət
  3. Torpaq, əmək, kapital, sahibkarlıq
  4. Pul, qızıl, valyuta
Cavabı göstər

C) Torpaq, əmək, kapital, sahibkarlıq

25. Tələb əyrisinin sağa sürüşməsinə nə səbəb ola bilər?

  1. Məhsulun öz qiymətinin azalması
  2. İstehsal xərclərinin artması
  3. Məhsulun öz qiymətinin artması
  4. İstehlakçıların gəlirinin artması (normal əmtəə üçün)
Cavabı göstər

D) İstehlakçıların gəlirinin artması (normal əmtəə üçün)
